# Blinded comprehension test

No participant results are recorded. Randomize labels `Program X`, `Program Y`,
and `Program Z` across the Lana, Python plain, and Python State-class versions.

Give each participant one layer at a time and record elapsed seconds plus one
point for each correct answer:

1. What state does this program maintain?
2. What causes the prediction to change?
3. Where are confidence and source weight represented?
4. How does stale evidence behave?
5. What happens when high-confidence sources conflict?

Do not tell participants which language is under evaluation. Keep language
experience, presentation order, and layer assignment in the result sheet so
future analysis can separate familiarity from comprehension.
