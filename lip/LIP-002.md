# LIP-002: Lazy graph inspection

- **Status:** Final
- **Author:** —
- **Date:** 2026-09-03

## Motivation

The VM builds a lazy `STATE_DIST` DAG but exposes no way to inspect its
structure. Tooling and debugging need a deterministic, machine-readable view of
the graph without forcing evaluation.

## Specification

- Expose the deterministic `STATE_DIST` structure as JSON and Graphviz DOT.
- Report node count, maximum depth, APPEND/TRANSFORM counts, exact-measurement
  support, sampling requirements, and available provenance metadata.
- Reuse the VM's existing lazy DAG and traversal rules.
- Measurement SHALL be read-only; it MUST NOT be described as collapsing the
  graph.
- A visual viewer is added only after the machine-readable contract is stable.

## Rationale

The DAG already exists and is traversed by the evaluators. Serializing its
structure is a read-only view over existing state, not a new evaluation path, so
it cannot alter semantics.

## Compatibility

No change to evaluation, bytecode, or resource limits. The JSON and DOT outputs
are additive surfaces.

## Test coverage

- JSON and DOT output for representative DAGs (Dirac, APPEND, TRANSFORM).
- Assert the reported node count and depth match the constructed graph.
