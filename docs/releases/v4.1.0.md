## Tap and release boundary

The separate 4.0.0 tap backfill is published at `oponite/homebrew-oponite` main commit `4671165bce6a999e39b1f4b8d61b45638859fd3e`. Its formula came from the published 4.0.0 asset; source digest and Homebrew audit, source install, test, and `lana version` were verified before the tap push. The tap README includes the `brew trust --formula` step. The Lana repository has a write deploy key scoped to that tap, stored as Actions secret `HOMEBREW_TAP_DEPLOY_KEY`. The exact `v4.1.0` tag ruleset is active (`24387417`).

The generalized release workflow and `tools/release_tap.py` are in the candidate; guard tests cover an already matching formula, downgrade refusal, same-version mismatch refusal, and injected Ruby rejection. The tap job checks the public source archive against the protected tag and keeps its write deploy key out of the formula audit/install step. The GitHub Release and tap are not atomic.

The candidate was merged through [PR #11](https://github.com/oponite/lana/pull/11). The protected annotated [`v4.1.0` tag](https://github.com/oponite/lana/releases/tag/v4.1.0) peels to the exact candidate commit `4e1606a390f44778029ff45bf0b8af7ff9b41272`. [Release workflow run 37080776610](https://github.com/oponite/lana/actions/runs/37080776610), attempt 2, passed all jobs. The public release contains checksummed source and universal macOS archives plus `lana.rb`; downloaded checksums passed. Its source archive is byte identical to the locally qualified archive.

The first tap job attempt failed because Homebrew checked out the tap's committed 4.0.0 formula during source install instead of the staged 4.1.0 formula. [PR #12](https://github.com/oponite/lana/pull/12) fixed the workflow for later releases by copying the verified formula into Homebrew's tap checkout before audit and install. This workflow fix is on `main` after the 4.1.0 tag. The exact public 4.1.0 formula was pushed to `oponite/homebrew-oponite` at commit `a6d109870b93615f356079a14287a8d2c0dd28e7`. On attempt 2, the tap job verified an already matching formula, built and tested its 4.1.0 source install, and confirmed `Lana 4.1.0 (LABC v2, Rust VM, native compiler)`.

Signing, notarization, and Homebrew Core submission remain deferred.
