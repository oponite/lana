# Lana 4.1.1 installer release

This patch prepares prebuilt installation for macOS Apple Silicon/Intel,
Linux x64/ARM64 with glibc 2.35+, and Windows x64/ARM64. It preserves the published
4.1.0 language behavior and corrects Windows compiler path handling and PATH
discovery; unrelated local development is excluded.
Homebrew remains optional and continues to receive the verified source formula.

The shell and PowerShell installers pin downloads to the selected release,
verify checksums and archive contents, and execute the bundled compiler and
standard library before promoting a staged installation. Upgrades replace the
installer-owned bundle and restore the previous bundle/configuration on errors.
Linux and Windows bundle SQLite; Windows release builds use a static C runtime.

Qualification is recorded against the exact candidate commit in build logs,
CI checks, the protected-tag release workflow, and the public release notes.
This checked-in description is not a claim that qualification or publication
has passed. Required checks follow AGENTS.md and docs/dev/RELEASE_CHECKLIST.md.

Native jobs qualify the Linux/Windows x64 and ARM64 bundles. The macOS
universal archive must execute both slices. Published-installer checks run on
all five platform/architecture combinations. Signing, macOS notarization,
and Homebrew Core submission remain deferred.
