# LIP-034: 512 MiB memory limit for the compiler

- **Status:** Final (accepted by the maintainer, 2026-11-07)
- **Author:** Vijay Neelakantan
- **Date:** 2026-11-07

## Motivation

The self-hosted compiler runs with 256 MiB of memory and 50,000,000 instructions.
Compiling the compiler itself (the bootstrap check) already used 49,667,380
instructions, 99.3% of the limit, so small compiler changes could no longer be
bootstrapped. A 20-line lexer fix measured 51.5M.

Most of that cost is not compiler work. Near its memory limit the VM collects
garbage often, and collection work is charged to the instruction budget. The same
bootstrap compile measured:

| Memory limit | Instructions |
|---|---|
| 256 MiB | 49.1M–51.6M, varying with unrelated edits |
| 384 MiB | 45.5M–45.8M |
| 512 MiB | 44.0M–44.1M |
| 1024 MiB | 41.5M–41.6M |

The instructions the compiler itself executes are about 41.5M. The rest is
collection under memory pressure, and it changes unpredictably with small edits
(adding one empty function lowered the total by 380K).

## Specification

- The compiler runs with a 512 MiB memory limit. This applies wherever the
  compiler bytecode runs: `lana run`, `check`, `compile`, `build`, the LSP, and
  the WASM build.
- The compiler instruction limit stays at 50,000,000.
- Programs are unchanged: their default memory limit stays 256 MiB.
- Exhaustion of either limit is still an error and never emits partial bytecode.

## Rationale

The instruction limit bounds compiler work and stays. The memory limit is what
makes the work measurement unstable: at 256 MiB the bootstrap is within a few
percent of the limit, and whether it fits depends on when collections happen.
At 512 MiB the bootstrap uses about 44M instructions (12% headroom), and the
remaining variation is small.

Reducing the compiler's peak memory would also work, but its source is not yet
identified. That remains worthwhile and is not blocked by this change.

## Compatibility

- Programs: no change.
- Bytecode: no change.
- Compilation: a source that failed with `LANA_ERR_OOM` or `LANA_ERR_LIMIT` at
  256 MiB may now compile. Nothing that compiled before stops compiling.
- Hosts that run the compiler need up to 512 MiB instead of 256 MiB.

## Test coverage

- The bootstrap check (`native_compiler_bootstrap`) runs the compiler on its own
  source with 512 MiB and 50,000,000 instructions and requires byte-identical
  output twice.
- `tests/test_compiler_output.py` continues to check the instruction limit.
